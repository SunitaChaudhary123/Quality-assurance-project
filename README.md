# Quality Assurance Project

## Project Overview

This repository contains my practical Quality Assurance (QA) testing work based on the **MachineryExpo** web application.

The project focuses on understanding application requirements, identifying defects, validating APIs, checking database operations, and performing UI automation testing.

---

## Application Under Test

- **Project Name:** MachineryExpo
- **Application URL:** https://ourmachineryexpo.com
- **Project Type:** Web Application

---

## Project Objective

The main objective of this project is to gain practical experience in software testing and build a structured QA portfolio demonstrating different testing techniques.

---

## Testing Scope

The project covers the following testing areas:

### 1. Manual Testing
- Requirement Analysis
- Test Scenarios
- Test Case Design
- Functional Testing
- Positive and Negative Testing
- Bug Reporting
- Regression Testing

### 2. API Testing
- API Request and Response Validation
- Positive and Negative API Testing
- Status Code Validation
- Request Payload Validation
- Authentication Testing
- Postman Collections

### 3. SQL Testing
- SELECT Queries
- INSERT, UPDATE and DELETE Queries
- JOIN Operations
- Database Validation
- Data Verification

### 4. Automation Testing
- Python
- Playwright
- Pytest
- UI Automation
- Assertions
- Test Execution Reports
